为什么没读到微信？

这台电脑上的微信是 4.x 新版，它用自己画的弹窗提醒，不写进 Windows 通知中心。 所以我们（以及任何读系统通知的程序）都拿不到它。这不是 bug，是微信的实现方式。

三条路，按推荐顺序：

  1. 手机连接镜像（推荐）：设置 → 蓝牙和其他设备 → 手机连接 → 连上安卓手机、 允许「访问手机通知」。之后手机微信的消息会变成 Windows 系统通知， 本程序就能读到，来源会显示「手机镜像」。
  2. 手动补一条：展开左下角「手动补一条 / 自己粘一批」，把消息粘进来即可。
  3. 不做的事：破解微信本地数据库读聊天记录 —— 违反用户协议，作品也可能被判违规。

想自己查一遍？在程序文件夹里运行 py diagnose.py。
